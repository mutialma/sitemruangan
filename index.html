Cadangan & Pemulihan Data

Karena sistem ini berjalan secara static di peramban Anda, data tersimpan di LocalStorage. Anda bisa mengunduh cadangan kapan saja.

Unduh Cadangan Data

Simpan seluruh data ruangan dan jadwal ke dalam satu berkas JSON di laptop atau komputer Anda.

Pulihkan Data

Unggah berkas cadangan JSON yang sebelumnya pernah diunduh untuk memulihkan data ruangan dan jadwal.

Kembalikan Data Awal

Reset data ke kondisi awal Excel (1 ruangan, 7 kegiatan default). Hati-hati, aksi ini akan menimpa data yang telah Anda tambahkan.
